# SecureGuard Financial Fraud Analysis

An interactive Power BI portfolio project exploring labeled credit card fraud across 20,000 sample transactions. The sample contains 112 labeled fraud cases, a baseline fraud rate of 0.56%.

The report tracks fraud KPIs and compares transaction patterns by month, merchant category, state, and gender.

## Open the report

1. Download [SecureGuard-PowerBI-Project.zip](./SecureGuard-PowerBI-Project.zip) and extract it.
2. Open `SecureGuard.pbip` in Power BI Desktop on Windows.
3. Select **Home → Refresh** to load the embedded sample if the visuals are blank.
